# SettleIn — Relocation Life-Setup Navigator

Welcome to **SettleIn**, an autonomous digital experience built for the Microsoft Agent-a-thon 2026.

SettleIn transforms the fragmented, stressful process of moving to a new city into a seamless, delightful, and highly intelligent digital experience.

## Features
- **Intelligent Neighborhood Matcher**: Find the perfect community based on your lifestyle, commute, and budget.
- **Pack & Move Inventory**: Digital checklist to track items, fragiles, and logistics seamlessly.
- **Agent Chatbot**: Get AI-powered advice on local utilities, healthcare, schools, and city-specific context.
- **Document Tracker**: Organize and verify critical relocation documents securely.
- **Admin Gateway**: Role-based access for department approvals and processing.

## Running Locally
1. Navigate to the `settlein` directory:
   ```bash
   cd settlein
   ```
2. Start the local server:
   ```bash
   npm start
   # or
   node server.js
   ```
3. Open `http://localhost:8080` (or the port specified by the server) in your browser.
